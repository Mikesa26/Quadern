Com publicar: 1) afegeix o edita coses aquí, 2) prem «Descarregar data.json», 3) a GitHub, Add file > Upload files, puja'l (substitueix l'anterior) i Commit. En ~1 minut es veu a la web. Per a PDFs o imatges: puja'ls igual a GitHub i posa a «Enllaç o fitxer» el nom (ex. fitxers/tema3.pdf) o enganxa un enllaç (Drive, etc.).
